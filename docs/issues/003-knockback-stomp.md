# 이슈 003 — 옆에서 맞았는데 오답 동사를 얻는다

- 발견: 2026-10-18, F06·F07 브라우저 점검 중. climb를 얻은 뒤 가만히 있었더니 HUD 동사가 sleep으로 바뀌어 있었다.
- 영향: 플레이어가 고르지 않은 오답 동사를 얻는다. "맞는 동사를 골라야 길이 열린다"는 학습 장치가 무너진다.

## 재현

회색 상자 맵에서 climb 적을 밟고 가만히 둔다. sleep 적이 걸어와 옆에서 닿는다.

헤드리스 재현(`stepWorld` 로그, 1/60초 스텝):

| 스텝 | 사건                                                                 |
| ---- | -------------------------------------------------------------------- |
| 11   | verb_gained climb                                                    |
| 267  | hurt (주인공 x 1080, 적 x 1090)                                      |
| 277  | verb_gained **sleep** — 넉백으로 떴다가 다가오던 적 위로 떨어져 밟음 |

## 원인

1. 넉백 속도(70px/s)가 공중 감속(decel 900 × airControl 0.75 = 675px/s²)에 0.1초 만에 사라져 실제로는 3.6px만 밀려났다.
2. 적은 주인공을 친 뒤에도 같은 방향으로 계속 걸어 공중에 뜬 주인공 밑으로 들어갔다.
3. 내려오는 주인공은 밟기 판정을 받았다.

## 수정

- 맞은 직후 300ms(`HURT_STUN_MS`, 제안값) 동안 조작을 잠그고 넉백 속도를 유지한다(`StepMods.keepVx`). 이제 약 20px 밀려난다.
- 적은 주인공을 친 뒤 반대로 돌아선다. 벽에 몰린 주인공 밑으로 파고드는 일도 막는다.

## 재발 방지

`world.test.ts`에 테스트 3개를 추가했고, 수정을 하나씩 지워 각각 실패하는 것을 확인했다.

- 옆에서 맞고 밀려난 뒤 원치 않은 동사를 얻지 않는다
- 경직 동안 넉백 속도가 유지돼 15px 넘게 밀려난다
- 벽에 몰려 있어도 적이 돌아서서 밑으로 파고들지 않는다
