# 맵 규칙 (Tiled .tmj)

`public/maps/commute.tmj`는 `npm run map:commute`(scripts/gen-commute-map.mjs)로 만든 **초안**이다.
Tiled에서 열어 다듬으면 그때부터는 .tmj가 원본이다. 스크립트를 다시 돌리면 덮어쓰니 주의한다.

## 맵

- 직교(orthogonal), 무한 맵 아님, 타일 10×10px. 높이 18칸(화면 180px).
- 땅 윗면은 16행, 주인공이 서 있는 칸은 15행.
- 타일셋은 맵에 포함(Embed)한다. 외부 타일셋(.tsj)은 아직 읽지 못한다.

## 레이어

| 이름      | 종류            | 내용                                                                                                     |
| --------- | --------------- | -------------------------------------------------------------------------------------------------------- |
| `tiles`   | 타일 레이어     | 타일셋 타일의 `kind` 속성으로 종류를 정한다: `solid`(땅·벽), `oneway`(한 방향 발판), `cracked`(금 간 벽) |
| `objects` | 오브젝트 레이어 | 아래 오브젝트. 위치는 사각형 왼쪽 위가 든 칸으로 정한다                                                  |

## 오브젝트 (Tiled의 Class = JSON의 type)

| type          | 속성              | 뜻                                                                                              |
| ------------- | ----------------- | ----------------------------------------------------------------------------------------------- |
| `spawn`       | —                 | 시작 위치(0번 체크포인트). 맵에 하나                                                            |
| `checkpoint`  | —                 | 구간마다 하나. 구멍에 빠지면 지나온 것 중 가장 오른쪽에서 다시 시작                             |
| `enemy`       | `verb`            | 동사 적. verb는 스테이지 동사 데이터에 있어야 한다                                              |
| `letter`      | `char`, `ability` | 철자 코인. ability: `climb`·`float`·`break`·`none`(레벨 점검이 이 능력을 쓴다고 보고 도달 검사) |
| `door`        | —                 | 회사 문. 사각형 전체가 판정 범위                                                                |
| `ability-gap` | —                 | float처럼 능력이 있어야 건너는 틈. 사각형이 덮는 열 범위를 레벨 점검이 의도된 틈으로 본다       |

## 레벨 점검 (`npm test`의 `commute.test.ts`, 하나라도 실패하면 CI 실패)

- 모든 발판 끝에서 앞뒤로 달려 뛰어 구멍 착지 0곳(`ability-gap` 제외)
- `ability-gap`은 float 없이 달려 뛰면 건널 수 없어야 한다
- 철자 코인 모두 닿을 수 있다(코인 근처 윗면에서 시뮬레이션하는 근사 검사, 경로 전체는 보지 않음)
- R은 float 없이는 닿을 수 없다
- 높이는 맵 바닥이 아니라 땅 윗면부터 센다
