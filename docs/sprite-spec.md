# 도트 리소스 사양 (F12) — 직접 그릴 것

지금 `public/sprites/`에 있는 그림은 `npm run sprites:placeholder`로 만든 **자리표시**다. 같은 파일 이름·태그 이름으로 Aseprite에서 내보내 덮어쓰면 게임이 그대로 읽는다. 하나라도 빠지거나 형식이 틀리면 게임은 회색 상자로 그리고 콘솔에 이유를 남긴다.

## 내보내기 (Aseprite)

- File → Export Sprite Sheet
  - Layout: Horizontal Strip(가로 한 줄) 권장
  - Output: JSON Data 켜기, **Array** 또는 **Hash** 둘 다 됨, **Meta: Tags 켜기**
  - 파일: `public/sprites/<이름>.png`, `public/sprites/<이름>.json`
- 프레임 속도는 게임이 정한다(9프레임마다 다음 그림, 약 0.15초). Aseprite의 duration은 쓰지 않는다.
- 색 수 제한은 없다. 투명 배경. 확대는 게임이 nearest로 한다.

## 시트와 태그

| 파일    | 한 칸 크기 | 기준점                                                   | 태그(꼭 있어야 함)                                                                                                                                                                                       |
| ------- | ---------- | -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `hero`  | 16×16      | 아래 가운데(발) — 충돌 상자 10×14가 가운데 아래에 맞는다 | `idle`(서기) · `walk`(걷기) · `jump`(오를 때) · `fall`(떨어질 때) · `climb`(오르기) · `float`(뜨기) · `break`(부수기) · `sleep`(오답: 꾸벅) · `dance`(오답: 춤) · `skid`(오답: 끼익 멈춤) · `hurt`(맞음) |
| `enemy` | 16×16      | 아래 가운데 — 충돌 상자 12×12                            | `walk` · 머리 위 동사 글자는 게임이 그린다(그림에 넣지 않는다)                                                                                                                                           |
| `coin`  | 8×8        | 가운데                                                   | `spin`(4프레임)                                                                                                                                                                                          |

- 주인공은 **오른쪽을 보는** 그림으로 그린다. 왼쪽은 게임이 뒤집는다.
- 오답 동작 3종은 색만이 아니라 **동작으로** 알아볼 수 있어야 한다(PRD 접근성).

## 타일셋

`public/maps/graybox-tiles.png` (30×10, 칸 10×10) — 왼쪽부터 `solid`(땅·벽) · `oneway`(한 방향 발판, 위 3px만 밟는 면) · `cracked`(금 간 벽). Tiled 맵이 이 이미지를 쓴다. 칸을 더하려면 Tiled에서 타일셋을 늘리고 타일 속성 `kind`를 단다(docs/level-format.md).

> 게임 화면은 아직 타일을 Graphics로 그린다(타일셋 이미지를 바꿔도 게임 화면 타일은 그대로). 타일셋 그림을 게임에 반영하는 것은 그림이 준비되면 한다.

## 철자 코인

게임이 노란 원 + 글자로 그린다. 그림으로 바꾸려면 `letter` 시트(10×10, 태그 `idle`)를 더하고 렌더러에 연결한다(아직 미구현).
