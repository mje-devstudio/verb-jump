# 작업 카드 — F17 동사 도감 (로컬 초안)

- **목표(PRD)**: 일시정지 메뉴에서 만난 동사의 뜻, 발음, 예문을 다시 본다.
- **책임 / 검토**: 셀리아 / 베스퍼(같은 세션이라 "자기 점검")
- **기준**: `F29-level-warnings`(efce5e1, PR #3) 위 → 브랜치 `F17-verb-book`

## 정한 것 (제안값, PRD에 없음)

- **"만난 동사"**: 밟아서 얻은 동사(맞는 동사·오답 동사 모두)와 철자로 완성한 단어. 이 기기에 저장해 판이 끝나도 남는다(`verb-jump:met-verbs`). 저장이 막혀도 이번 실행 동안은 기억한다.
- **아직 만나지 않은 동사**: "??? · 아직 만나지 않은 동사"로 가린다(직접 밟아 보게). 개수는 "3 / 6"처럼 보인다.
- **오답 동사**: 점선 테두리와 "(오답 동사)"로 구분한다(색만으로 구분하지 않음).
- **일시정지 화면**: 기존 "일시정지 · Esc로 계속" 안내를 메뉴(계속하기 · 동사 도감)로 바꿨다. 멈출 때마다 메뉴부터 보이고 계속하기에 포커스가 간다. Space는 게임 점프 키라 막혀 있어 버튼은 Enter·클릭·탭으로 누른다.

## 검증

- `PauseMenu.test.tsx`(6개): 멈추면 메뉴·포커스·계속하기, 만난 동사 상세와 가림(2 / 6), 듣기 → TTS 호출, 다시 멈추면 메뉴부터, 저장 순서·중복·깨진 저장값
- 전체: 31개 파일 207개 테스트, 타입·린트·포맷 통과
- 브라우저(개발 서버): 게임 중 Esc → 메뉴, 계속하기 포커스, 도감 3 / 6. 740×360(휴대폰 가로)에서 패널이 화면 안에 들어오고 스크롤됨

### 미검증·남은 것

- 실제로 적을 밟아 기록되는 흐름은 단위 테스트가 없다(`onVerbGained` → `onVerbMet` 연결은 코드로 확인). 브라우저 패널은 백그라운드라 게임이 돌지 않아, 도감 기록은 저장소에 직접 넣어 확인했다.
- TTS 실제 소리, 실기기 터치
- 첫 화면 JS 변화 없음(gzip 88.54kB). 도감은 게임 화면 조각에 들어간다(gzip 87.39 → 88.19kB)

### 볼륨 조절 (사용자 의견 2차, 2026-10-20)

- 의견: "영어 읽어 주는 소리가 수정이 안 됐다. 볼륨을 직접 조절할 수 있게."
- 확인: 앞의 수정(효과음 줄이기)은 PR #4에만 있고 운영에는 아직 반영되지 않았다. 브라우저 TTS 볼륨은 1.0이 최대라 그 이상 키울 수 없다.
- 바꾼 것: 타이틀("볼륨 조절" 펼치기)과 일시정지 메뉴("소리")에 발음 볼륨·효과음 볼륨 슬라이더(10% 단위, 저장), "들어 보기". 효과음 기본값을 60%로 낮춤. 슬라이더에 포커스가 있으면 방향키를 게임이 가로채지 않음.
- 테스트: `VolumeControls.test.tsx`(5), `sfx.test.ts` 볼륨×줄이기, `input.dom.test.ts` 입력란 키, 일시정지 메뉴 "소리"
- 더 키우려면: 브라우저 TTS 대신 녹음한 발음 파일을 Web Audio로 키워 재생하는 방법이 있다. 녹음 음성(직접 녹음 또는 라이선스가 맞는 음성)을 정해야 해서 이번에는 하지 않았다.
