# 작업 카드 — F08 1스테이지 구간 1~4 (로컬 초안)

- **목표**: Tiled 맵으로 1스테이지 구간 1~4를 만들고, 구간마다 체크포인트를 두고, 회사 문에 닿으면 클리어.
- **책임 / 검토**: 셀리아 / 베스퍼(같은 세션이라 "자기 점검")
- **브랜치**: `F08-commute-map` ← `F06-F07-stomp-abilities`(ecbf72d). 앞 브랜치들이 아직 main에 합쳐지지 않아 쌓아서 진행.
- **제외 범위**: 스테이지 API로 맵 받기(F01), 철자 코인 줍기·HUD(F27), 결과 화면(F11), 도트 타일셋(F12), 화면 밖 타일 컬링(F03·F19)

## 구간 배치

| 구간           | 소개                          | 고르기                                                                | 철자                         |
| -------------- | ----------------------------- | --------------------------------------------------------------------- | ---------------------------- |
| 1 집 앞 담장   | climb 적 → 낮은 담장 5칸      | climb·sleep → 높은 담장 8칸                                           | B: 높은 담장 위              |
| 2 옥상 사이    | float 적 → 짧은 틈 6칸        | float·dance → 넓은 틈 14칸                                            | R: 넓은 틈 한가운데 11행     |
| 3 공사장       | break 적 → 금 간 벽(천장까지) | break·brake → 두 번째 금 간 벽                                        | E·A: 각 금 간 벽 너머        |
| 4 회사 앞 골목 | —                             | climb·sleep → 담장 7칸, float·dance → 틈 10칸, break·brake → 금 간 벽 | K: 가장 높은 한 방향 발판 위 |

담장은 최고 점프 높이(42.75px)보다 높고, 틈은 달려 뛰기 거리(51px)보다 넓어서 능력 없이는 지나갈 수 없다.

## 함께 바꾼 규칙

- **맵 위는 천장**: 맵 위쪽 바깥을 벽으로 본다. climb로 벽을 타고 맵 위로 나가는 문제(F06·F07 카드의 남은 것)를 막았다.
- **적 다시 생기기**(제안값 5초, 화면 밖일 때만): 오답 동사를 밟은 뒤 맞는 동사 적이 이미 사라져 있으면 길이 막힌다. PRD는 "체크포인트에서 다시 생긴다"만 정해 두어, 이 규칙을 더했다.
- **회사 문 클리어**: 닿으면 `stage_clear` 알림을 한 번 보내고 세계를 멈춘다. 지금은 "출근 완료!" 표시만 하고, 결과 화면은 F11에서 만든다.

### 판단 기록

- **R 위치**: 처음엔 12칸 틈의 12행에 두었는데, 도달 검사가 float 없이도 닿는다고 잡았다. 반대쪽 끝에서 달려 뛰면 더 쉽게 닿았다. 계산해 보니 12칸 틈에서는 float 없이 닿지 않는 자리가 2px밖에 안 되어, 틈을 14칸으로 넓히고 R을 한가운데 11행에 두었다. 도달 검사도 발판 끝에 1px만 걸친 출발을 넣도록 고쳤다. 그 전에는 칸 가운데에서만 출발해 실제보다 덜 멀리 뛰었다.
- **맵을 fetch로 받기**: F01(스테이지 API, TanStack Query) 전까지는 `/maps/commute.tmj`를 직접 받는다. 개발 모드 StrictMode 이중 마운트로 두 번 요청되는데, F01에서 캐시로 정리한다.

### 미검증·열린 질문

- **고르기가 강제되지 않음 (기획 확인 필요)**: 소개 적에게서 얻은 맞는 동사를 그대로 들고 고르기 구간을 지나갈 수 있다. 오답을 실제로 고르게 하려면, 고르기 구간 앞에서 능력을 잃게 하거나 소개 구간 끝에 능력이 필요 없는 출구를 두는 등의 기획 결정이 필요하다.
- 실제로 한 판 끝까지 하는 플레이(클리어 시간, 3분 시계 안에 끝나는지)는 미확인. 맵 길이는 3,700px, 최고 속도로 달리기만 하면 약 41초다.
- 철자 코인 도달 검사는 근사다. 시작한 윗면까지 실제로 갈 수 있는지(경로)는 F29에서 본다.
