# 작업 카드 — F10 · F03 · F12 모바일 조작, 게임 화면, 도트 리소스 (로컬 초안)

- **목표**: 휴대폰 가로 화면에서 두 엄지로 같은 스테이지를 끝낼 수 있게 하고, 게임 화면을 마무리하며(정수 배율·카메라·화면 밖 타일 생략), 도트 리소스를 끼울 자리를 만든다.
- **완료 기준**
  - F10: 가로 화면, 왼쪽 절반에 엄지를 대면 생기는 좌우 이동 패드, 큰 점프 버튼, 지금 동사가 적힌 동사 버튼(능력이 있을 때만). 두 엄지 동시 입력, 스크롤·확대·길게 누르기 메뉴 차단, 세로면 회전 안내, 노치를 피한 배치, 모바일 판정 완화(밟기 폭 +20%, 발판 끝 유예 0.15초). 터치 영역 44pt 이상, 누른 상태 표시.
  - F03: 320×180 고정 해상도, 정수 배율, nearest, 레터박스, 카메라 추적, 화면 밖 타일 그리지 않기.
  - F12: 주인공(서기·걷기·점프·오르기·뜨기·부수기·오답 3종), 동사 적 1종, 코인 4프레임, 철자 코인, 한 방향 발판이 든 타일셋. 갈무리 폰트(OFL 파일 포함), jsfxr 효과음.
- **책임 / 검토**: 셀리아·타비 / 베스퍼(같은 세션이라 "자기 점검")
- **브랜치**: `F10-F03-F12-mobile-screen-assets` ← `F01-F02-F11-stage-api-result`(b043c84)
- **사람이 할 일**: F12의 도트 그림은 PRD상 직접 그린다. 이번 작업은 그림을 끼울 파이프라인·사양서·대체 그림(회색 상자)까지. 그림이 없으면 회색 상자로 그린다.
- **실기기**: 실제 휴대폰 확인은 이 작업에서 못 한다(같은 Wi-Fi 접속 또는 배포 F13 뒤). 브라우저 모바일 크기 흉내로만 확인한다.
- **현재 단계**: 검토(자기 점검 완료, 독립 검증 미실행)

### 판단 기록

- **HUD를 게임 화면 위에 겹침**: 휴대폰 가로(높이 약 390px)에서 HUD를 위에 따로 두면 정수 배율이 1배(320×180)로 떨어진다. 브라우저에서 실제로 1배가 되는 것을 보고 항상 겹치도록 바꿨다(2배 640×360). 데스크톱에서도 낮은 창이면 같은 문제가 있었다.
- **일시정지 사유 분리**: 사용자 일시정지·탭 이탈·세로 화면을 따로 세어, 사용자가 멈춘 뒤 탭을 다녀오거나 가로로 돌려도 저절로 시작하지 않는다. 앞서 확인하지 못했던 "탭 이탈 → 3초 뒤 재개"를 이번에 테스트로 확인했다.
- **콜백 ref**: `onReady`를 effect 의존성에 넣으면 렌더마다 게임(루프·렌더러)을 다시 만들게 된다. 린트 경고로 찾아 최신 콜백을 ref로 읽게 했다.
- **스프라이트 프레임은 게임 프레임으로**: PixiJS의 AnimatedSprite 타이머 대신 게임 프레임 수로 프레임을 고른다(일시정지와 함께 멈추고 결정적).
- **스프라이트시트 텍스처는 화면을 떠날 때 지우지 않음**: Assets 캐시가 다음 판(다시 하기)에서 같은 텍스처를 돌려주므로, 지우면 두 번째 판에서 깨진다. 그래픽·글자·WebGL 문맥은 지운다.
- **갈무리는 게임 화면에만**: 500KB라 타이틀·결과(Lighthouse 대상)에는 쓰지 않는다.
- **효과음 정의 고정**: jsfxr 프리셋은 매번 무작위라 한 번 만든 정의를 코드에 고정했다(`npm run sfx:gen`으로 다시 만들 수 있음).

### 미검증·남은 것

- **실제 휴대폰**: 두 엄지 동시 입력, 노치·홈 바, iOS 소리·발음, 120Hz·저전력 모드는 실기기에서 확인해야 한다(P1 모바일 실기기 리뷰). 지금은 브라우저 흉내와 포인터 이벤트 테스트만 했다.
- **직접 그린 도트**: 주인공·적·코인·타일셋 그림은 사람이 그린다(`docs/sprite-spec.md`). 지금 화면은 자리표시 그림이다.
- **타일셋 이미지**: 게임 화면 타일은 아직 Graphics로 그린다. 타일셋 그림이 준비되면 텍스처로 바꾼다.
- 효과음 실제 소리는 브라우저에서 듣지 못했다(소리 출력 확인 불가). 소리 연결은 테스트로만 확인했다.
- 갈무리 폰트 500KB의 부분 집합(서브셋)은 하지 않았다. F19 성능 개선 때 검토한다.
- 효과음 볼륨(0.2)과 소리 고르기는 플레이테스트에서 다듬는다.
