### 판단 기록

- **rAF 오류**: React 에러 바운더리는 렌더 중 오류만 잡는다. 게임 루프 오류를 상태로 받아 렌더에서 다시 던져, 같은 다시 시작 화면을 쓴다. 매 프레임 같은 오류가 반복되지 않게 루프는 멈춘다.
- **대표 이미지**: 그린 그림이 아니라 실제 게임 화면을 캡처한다. 도트가 바뀌면 같은 방법으로 다시 만든다. 개발 서버 전용 저장 경로(`/__dev/save-og`)는 배포에 없다.
- **절대 주소**: 페이스북 등은 `og:image` 절대 주소가 필요하다. 배포 주소를 모르니 지어내지 않고 환경 변수로 비워 두었다.
