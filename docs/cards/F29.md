# 작업 카드 — F29 레벨 점검 스크립트 (로컬 초안)

- **목표(PRD)**: 맵을 불러올 때 모든 발판 끝에서 지금 수치로 앞뒤로 달려 뛰는 시뮬레이션을 돌려, 구멍에 떨어지는 곳과 닿을 수 없는 철자 코인을 개발 모드에서 경고한다.
- **책임 / 검토**: 셀리아 / 베스퍼(같은 세션이라 "자기 점검")
- **기준**: `main` b32fdfb + 문서 `docs-f19-lighthouse` → 브랜치 `F29-level-warnings`
- **이미 있던 것(F08 때 선행)**: 점검 함수(`levelCheck.ts`)와, 실제 맵에 점검을 돌려 하나라도 걸리면 CI가 실패하는 테스트(`commute.test.ts`). 이번에는 "개발 모드에서 맵을 불러올 때 경고"를 더했다.

## 바꾼 것

| 파일                                        | 내용                                                                                                                    |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `src/game/level/levelCheck.ts` `checkLevel` | 구멍 착지 + 닿을 수 없는 철자 코인을 경고 목록(문구·맵 위 자리)으로 모은다. CI 테스트와 같은 함수를 쓴다                |
| `src/features/devtools/levelWarnings.ts`    | 점검 결과 저장소. 타이틀에서 맵을 받으면(개발 빌드·`?dev`) 한 번 점검하고 콘솔에도 `[레벨 점검]` 경고를 남긴다          |
| `DevPanel.tsx`                              | 개발자 토글에 "레벨 점검: 경고 N건 · Nms"와 목록, "게임 화면에 경고 자리 표시" 켜기/끄기                                |
| `grayboxRenderer.ts` `setLevelMarks`        | 경고 자리를 맵 위에 빨간 테두리로(구멍은 발판 끝 칸, 철자는 코인 칸)                                                    |
| `scripts/vite-dev-api.ts`                   | 브라우저가 취소한 요청(StrictMode 이중 마운트·페이지 이동)을 서버 오류로 올리던 것을 무시(개발 서버 전용, 확인 중 발견) |

- 점검 코드는 개발자 토글을 쓸 때만 받는 별도 조각(`levelCheck-*.js`, gzip 1.29kB)이다. 첫 화면 JS는 gzip 87.88 → 88.53kB(개발자 토글 UI·저장소).

## 검증

- `levelCheck.test.ts`: 8칸 구멍과 땅에서 10칸 위 철자 코인이 있는 맵 → 구멍 경고(자리 포함)와 철자 경고. 능력용 틈으로 표시하면 경고 없음
- `levelWarnings.test.ts`: 경고를 저장소·콘솔에 남기고 같은 맵은 다시 점검하지 않음, 안전한 맵은 0건
- `DevPanel.test.tsx`: 경고 수·시간·목록 표시, 표시 켜기/끄기
- 전체: 30개 파일 201개 테스트, 타입·린트·포맷 통과
- 브라우저(개발 서버): 실제 맵 "경고 0건 · 33ms". 경고를 일부러 넣고 게임을 시작하면 맵 위에 빨간 테두리 두 개

### 미검증·남은 것

- 손맛 수치를 화면에서 바꾸는 기능은 없어서, "수치를 바꾸면 다시 점검"은 테스트(수치를 바꾸면 CI의 맵 점검이 다시 돎)로만 한다.
- 코인(철자 아닌) 도달 검사는 CI 테스트에만 있다(PRD 경고 대상이 아니라 화면 경고에는 넣지 않음, 실제 맵에서 52ms).
- 철자 도달 검사는 근사다(시작 윗면까지 실제로 갈 수 있는지는 보지 않음).
